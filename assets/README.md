# Profil görselleri

Koyu mekanik kapak ve kısa proje kartları. Harici istatistik servisi veya takip yok.

- Kapak: 1280 × 460; 200 kare, 40 ms/kare, 8 saniyelik döngü.
- Dişliler, gösterge ve bant tam periyot tamamlar. Tam kare / arka plan temizleme
  yöntemi önceki kareden iz kalmasını önler.
- Hareket azaltma tercihi için sabit PNG alternatifi vardır.
- Kartlar: 620 × 242 PNG; bağlantılar ve alternatif metinler README'de.
- Üretim: Python 3 + Pillow ile `python3 tools/render_workshop.py`.
  Nimbus Sans Bold ve DejaVu Sans Mono font yolları betiğin başındadır.

Önceki sürümler: `profile-before-dark-2026-10-16` ve
`profile-before-workshop-2026-10-16` Git etiketleri.
