# Profil görselleri

Bu profil için kodla çizilmiş atölye animasyonu ve proje kartları.
Harici istatistik servisi, ziyaretçi takibi veya uzaktan üretilen görsel kullanılmaz.

- Kapak: 1280 × 770, 120 kare, 12 saniyelik döngü, yaklaşık 660 KB.
- `prefers-reduced-motion: reduce` için aynı kapağın sabit PNG sürümü vardır.
- Proje kartları: 620 × 302 PNG; bağlantı ve erişilebilir açıklamalar README'dedir.
- Üretim: Python 3 + Pillow ile `python3 tools/render_workshop.py`.
  Çizici Nimbus Sans Bold ve DejaVu Sans Mono fontlarının Linux yollarını kullanır.
  Başka bir sistemde betiğin FONT ve MONO yollarını eşdeğer fontlara ayarla.

Önceki profil: `profile-before-workshop-2026-10-16` Git etiketi.
Geri dönüş için o etiketin README.md dosyasını yeni bir commit ile geri getir;
geçmişi silmek veya force push yapmak gerekmez.
